# HG Arena: сборка Minecraft 1.20.1 Forge

Сборка для своих: Forge 1.20.1 (47.4.28), Gacha Addiction, арена Hunger Games и ~60 модов.

## Как играть

1. Скачайте **[HGArenaLauncher.exe](../../releases/latest/download/HGArenaLauncher.exe)**.
2. Запустите его, введите ник (латиница, 3-16 символов), выберите память (лучше 8 ГБ) и нажмите **Играть**. Игра сразу подключится к нашему серверу.
3. Первый запуск качает Minecraft, Java, Forge и моды (около 1,5 ГБ), это займёт время. Потом лаунчер докачивает только изменения.

Аккаунт Mojang/Microsoft не нужен. Игра ставится в `%APPDATA%\.hgarena` (кнопка «Папка игры»).
Если Windows SmartScreen ругается: «Подробнее» -> «Выполнить в любом случае».

Галочка «Проверить все файлы» заново сверяет все файлы игры и модпака, если что-то сломалось.

## Скины

В сборке есть CustomSkinLoader: скин берётся с [Ely.by](https://ely.by) по нику.
Зарегистрируйтесь на ely.by с **тем же ником**, что вводите в лаунчере, и загрузите там скин. Скин увидят все игроки сервера.

## Для автора сборки: как обновить

Моды и конфиги берутся из `C:\Games\Minecraft`. После изменений:

```
python publish.py
```

Новые/изменённые моды загрузятся в релиз `files`, конфиги в `pack/files`, манифест обновится. Друзьям достаточно перезапустить лаунчер.

Если менялся сам лаунчер: увеличьте `LAUNCHER_VERSION` в `launcher/launcher.py` и запустите `python publish.py --launcher`.
